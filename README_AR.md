# مصاريف الحديثة — مشروع أندرويد

هذا مشروع مصدر لتطبيق أندرويد مستقل بسيط باللغة العربية. يستهدف Android 15 (targetSdk 35) ويعمل من Android 6.0 فما فوق (minSdk 23).

## الوظائف الحالية
- تسجيل دخل ومصروف بمبلغ وتصنيف وملاحظة وتاريخ.
- عرض الرصيد وإجمالي الدخل والمصروفات.
- عرض آخر العمليات والسجل الكامل.
- تصدير العمليات بصيغة CSV عبر قائمة المشاركة/الحفظ في الهاتف.
- تخزين محلي في SQLite، دون إرسال بياناتك إلى خادم.

## إنشاء APK
1. ثبّت Android Studio حديثًا على كمبيوتر.
2. فك ضغط الملف وافتح مجلد `MasareefModern` من Android Studio.
3. وافق على تنزيل Android Gradle Plugin / SDK إذا طلب البرنامج ذلك.
4. من القائمة اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ستجد الملف غالبًا في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة
- هذا إصدار أولي قابل للتطوير، وليس نسخة مطابقة للتطبيق القديم.
- لم يُرفق APK جاهز؛ بيئة الإنشاء هنا لا تحتوي على Android SDK/Gradle لبناء واختبار APK فعلي. المشروع المصدر هو الملف القابل للتسليم حاليًا.
- قبل استخدامه كسجل مالي أساسي، اختبر إدخال البيانات والتصدير وخذ نسخًا احتياطية دورية.
